# NexAfrica Data Analysis Internship Workspace

## Project Overview
End-to-end data analysis of the Superstore retail dataset to evaluate sales trends, regional performance, customer profitability, and the impact of discounting strategies across sales channels.

---

## Tech Stack
* **Language:** Python 3.14 (Pandas, NumPy, Matplotlib, Seaborn)
* **Database:** SQLite / SQL
* **Environment:** VS Code & Jupyter Notebooks
* **Version Control:** Git & GitHub

---

```text
